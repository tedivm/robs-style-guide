Glossary

Primary — Pink accent (`#de38a8`). Used for headings, buttons, and focal elements.
Secondary — Purple accent (`#b96dff`). Used for h2 headings and supporting UI elements.
Accent — Cyan accent (`#01cdfe`). Used for links, inline code, card headers, and tertiary buttons.
