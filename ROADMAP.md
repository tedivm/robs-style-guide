# Roadmap

## Theme

1. **Dark mode as default everywhere** — Svelte currently defaults to light mode; align both implementations to dark as default
2. **Review all hardcoded colors not part of variables** — audit CSS and components for any hex values not using `--primary`, `--secondary`, `--accent`, etc.
3. **Fix code examples to use syntax highlighting outside of Prism page** — inline code blocks on non-Prism pages should be highlighted

## UI

4. **Better tables — header rows** — improve `th` styling, add sticky headers, visual distinction from body rows
5. **Theme toggle (light/dark) icons** — replace text toggle with icon-based toggle using Tabler Icons
6. **Gradient icon examples** — showcase icons with gradient fills, gradient backgrounds, and gradient overlays
